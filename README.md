Обратите внимание: частота понижается у медведей — на слух это интуитивно «падающая» интонация, у быков наоборот. Если включить SOUND_FOR_NEUTRAL = True, нейтральный сигнал даст короткий 500 Гц бип — иногда полезно как «живой пульс», что скрипт не завис.

Что стоит проверить у себя

1. Windows: winsound.Beep работает всегда, но если терминал запущен в WSL/через SSH — переключится на \a.
2. QPython: модуль android может называться androidhelper — я пробую оба. Если оба падают (эмулятор без вибро) — останется \a.
3. range=1d + 1m: Yahoo реально отдаёт ~1300 баров за сутки для BTC, для золота 5d — несколько тысяч. ATR(14) считается нормально в обоих случаях.
